# Narriva — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Client reporting lead

- As a client-reporting lead, I want monthly portfolio letters generated for all households from the same fact rules, so that quality does not depend on who had weekend duty.
- As a client-reporting lead, I want missing-fact failures rather than guessed numbers, so that we never mail incorrect balances.

### Portfolio manager

- As a PM, I want to review ai-drafted fund commentary with tracked fact citations, so that I can add judgment without rewriting tables.
- As a PM, I want to reject a draft with reasons, so that template bugs get fixed.

### Compliance marketing reviewer

- As a compliance reviewer, I want template libraries with approved disclosures, so that writers cannot invent performance language.
- As a compliance reviewer, I want an archive of exactly what was sent, so that we can answer complaints.

### Data steward

- As a data steward, I want connectors to mark fields authoritative for generation, so that conflicting source systems cannot silently disagree in prose.

### Digital channel owner

- As a digital channel owner, I want the same narrative engine to power in-app explanations and PDF letters, so that channels do not diverge.
- As a digital channel owner, I want A/B tone variants within approved templates, so that we improve engagement without breaking compliance.

### Platform administrator

- As an administrator, I want tenant-isolated generation keys and audit logs, so that one firm’s facts never leak into another’s letters.
- As an administrator, I want to retire a template version with a forced migration, so that obsolete disclosures cannot be used.
